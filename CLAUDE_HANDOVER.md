## 2. Architecture and stack

### Frontend (`novacart-frontend`)

- One Next.js app (App Router, TypeScript strict), route groups: `(shop)` with `(storefront)`, `(auth)`, `(account)`, `(checkout)`; separate `(admin)` root layout (placeholder only so far). Same-origin **BFF** at `/api/bff/*`; the browser never calls the FastAPI backend and never holds tokens.
- Pinned versions (exact): next 16.4.2, react/react-dom 19.3.1, next-intl 4.14.9 (English only), zod 4.6.7, openapi-fetch 0.17.0, jose 6.2.12, pino 10.4.0, react-markdown 10.1.0, TypeScript 6.0.3 (pinned: typescript-eslint rejects 7), Vitest 5.0.5, pnpm 12.16.1, `minimumReleaseAge` 10080 min (14 days) in `pnpm-workspace.yaml`. Other dev tools in `package.json`. Tailwind CSS, Playwright, Testing Library, axe-core are used (versions: read `package.json`).
- Node: decided Node 24 LTS; **all my verification ran on Node 22**; the owner's Node version is unknown.
- Types: `spec/openapi.json` is a committed snapshot of the backend (`pnpm spec:sync <file>`, `pnpm spec:check` verifies its checksum). `src/generated/` is NOT committed and NOT in zips; `pnpm gen:api` regenerates it (runs on `pnpm install`, `pnpm build`, and now `pnpm typecheck`). **Stale generated types caused a tsc failure on the owner's machine once.**
- next-intl's Next plugin was removed from `next.config.ts` (it loads `@swc/core`, which failed on the owner's Windows with an SWC cache permission error); the alias is set directly. `turbopack.root` / `outputFileTracingRoot` are pinned to cwd (a parent folder had a `pnpm-workspace.yaml`). Dev-only `/media` rewrite to the API.
- Security design: `src/proxy.ts` (request id, CSP nonce, security headers, session refresh); sealed HttpOnly cookies (`nc_s` session, `nc_gc` guest cart, `nc_gp` guest payment capabilities; `__Host-` names in hardened envs; Path `/`); CSRF: strict Origin check + `X-NC-Csrf` header on every mutation, plus a per-page synchroniser token `X-NC-Sensitive` for change password, change email and address delete; server-side refresh with single flight; backend `Set-Cookie` is never forwarded to the browser (the BFF captures the guest cookies into its own sealed cookies); verified client IP forwarded; logs redact secrets.
- Deploy files: `deploy/{Dockerfile,Caddyfile,compose.dev.yaml,compose.prod-like.yaml}`; CI workflow `.github/workflows/ci.yml` (GitHub Actions assumed, **never run**).

### Frontend folder structure and enforced rules

`src/{app,components/{ui,layout,shared},config,features,hooks,lib,schemas,styles,types}`, `messages/en.json`, `tests/{unit,e2e,contract,helpers,stubs,reporters}`, `spec/`, `docs/`, `scripts/`, `deploy/`.

- Features (`src/features/<name>`): `account, addresses, authentication, cart, catalogue, categories, checkout, orders, returns, reviews, storefront`. Each has a client-safe public entry `index.tsx` and a server-only `server.ts`; other features import only those entries; wire types only in `lib/api` and feature `services/`.
- ESLint boundaries + dependency-cruiser (`pnpm lint`, `pnpm cycles`): shared code may not import `app` or `features`; no `process.env` or `NEXT_PUBLIC_` outside `src/config/env.server.ts`; arithmetic on money-named values banned outside `src/lib/money`; literal user-visible text banned in components (use `messages/en.json`); tests exempt from feature-internals and max-lines rules; files over 300 lines warn.
- `tests/protected-tests.json` lists security-critical test titles (53); `node scripts/check-protected-tests.mjs` fails if one is renamed or removed. **Renaming a protected test title requires updating that file.**
- **Housekeeping bug: `src/features/{catalogue,categories,reviews,storefront}/{components,services,utils}` is a stray literal-named empty directory tree** from a `mkdir -p` run under `sh` in M1. Not deleted (no code modified in this task); safe to delete after confirming it is empty.

### Backend (`FastAPI-E-commerce`)

- Python >= 3.12, FastAPI, SQLAlchemy 2 async + asyncpg, Alembic, PostgreSQL, Redis (cache, rate limits), Pydantic settings, PyJWT, passlib/argon2, slowapi, strawberry GraphQL (`/graphql`), Stripe SDK, aioboto3, cryptography. Managed with `uv`.
- Layout: `app/modules/<module>/{api,models,repositories,schemas,services,dependencies,exceptions}`, `app/core/*`, `alembic/`, `scripts/`, `docs/`, `tests/` (unit directories plus `tests/integration`). Modules: `addresses audit auth cart categories coupons email_settings invoices orders payments products reports returns reviews shipments site_config store tax users variants wishlist`.
- Conventions: exceptions carry a class attribute `code` (and optional `extra`) rendered by `app/core/exception_handlers.py`; `docs/openapi.json` and `docs/ERROR_CODES.md` are generated by `python -m scripts.export_api_docs` and checked by drift tests (**regenerate after any API or error-code change**); `alembic/env.py` imports models by hand (a guard test, `tests/test_alembic_env_models.py`, fails if one is missing); the project mixes CRLF and LF line endings, so **preserve each file's own endings** when editing; routers are registered in `app/main.py` (a test checks registration); access token 15 min, refresh token 7 days with rotation and family revocation.
- Backend facts that shape the UI: only an UNPAID order can be cancelled (paid orders go through returns and refunds); `fulfilled` means **shipped** (delivery is a shipment state); returns need a shipped order inside `RETURN_WINDOW_DAYS` (default 7); refunds are for a whole order; a GST tax invoice is issued automatically when a GST order is paid (customers cannot issue one); registration and login merge the guest cart; registration sends a verification email and never blocks sign-in; the backend has no self-service username update; register is rate limited to 5 per minute per IP; non-India delivery is refused when GST is on.
