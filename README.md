# FastAPI E-commerce

A production ready e-commerce backend built incrementally
with FastAPI, PostgreSQL, SQLAlchemy 2.x, and Alembic.

## Project & Environment

Currently implemented:
- Basic FastAPI app
- `/health` endpoint
- Environment-based configuration
- Docker + Docker Compose (app + PostgreSQL)

## Running locally

```bash
docker compose up --build
```

Then visit:
- http://localhost:8000/health
- http://localhost:8000/docs (Swagger UI, auto-generated by FastAPI)

## Stopping

```bash
docker compose down
```

To also wipe the database volume:

```bash
docker compose down -v
```


### Recreate API Container

If you update `.env` or change API environment variables, recreate the API container so the changes are loaded:

```bash
docker compose up -d --force-recreate api
```
